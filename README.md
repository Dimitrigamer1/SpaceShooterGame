Space Shooter 🚀

A fast-paced 2D space shooter game built with Python and Pygame.
Control your spaceship, avoid enemies and meteors, collect crystals, and survive as long as possible while increasing your score!

Pygame

🎮 Features
Smooth spaceship movement using WASD
Multiple enemy and obstacle types
Different collectible crystals with unique score bonuses
Health system
Real-time score tracking
Game Over screen
Custom assets and background
🕹 Controls
Key	Action
W	Move Up
S	Move Down
A	Move Left
D	Move Right
ESC / X	Exit Game
📦 Requirements

Before running the game, install:

Python 3.x
Pygame

Install Pygame with:

pip install pygame

▶️ How to Run
Clone the repository:
git clone https://github.com/Dimitrigamer1/SpaceShooterGame.git
Open the project folder:
cd space-shooter
Run the game:
python main.py
